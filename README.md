Проект посвящен автоматическому выделению зданий на аэрофотоснимках и расчету
площади застройки. Основная идея заключается в том, чтобы заменить ручную обработку
снимков нейросетевой моделью, которая определяет контуры зданий и формирует
бинарную маску застройки.
В качестве исходных данных использован открытый датасет INRIA Aerial Image Labeling
Dataset. Он содержит аэрофотоснимки городских территорий и соответствующие маски
зданий. Изображения имеют большой размер, поэтому перед обучением они
разбиваются на фрагменты 512×512 пикселей с перекрытием. Такой подход позволяет
работать с крупными .tif-файлами без потери качества на границах фрагментов.
Задача решается как бинарная сегментация: каждый пиксель относится либо к зданию,
либо к фону. Для этого используется модель LinkNet с энкодером ResNet-34. Обучение
выполняется на базе PyTorch и segmentation_models_pytorch. В качестве функции потерь
используется комбинация BCE Loss и Dice Loss, так как она хорошо подходит для задач, где
важно не только правильно классифицировать пиксели, но и сохранить форму объектов.
После обучения модель применяется к новому снимку по принципу скользящего окна.
Отдельные предсказания по фрагментам объединяются в единую маску. По этой маске
рассчитывается площадь застройки: число пикселей, отнесенных к зданиям, переводится
в квадратные метры с учетом масштаба изображения. Для демонстрации результата
реализован интерфейс на Gradio, где пользователь загружает .tif-файл и получает
изображение с выделенной застройкой и расчетом площади.
Качество модели оценивается метриками IoU, Dice, Precision и Recall. Дополнительно
сравнивается рассчитанная площадь застройки с площадью по эталонной маске.
В результате получен рабочий прототип, который автоматически выделяет здания на
аэрофотоснимках, строит маску застройки и рассчитывает ее площадь.
